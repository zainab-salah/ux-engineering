# Synthetic reference-led project section

A Next.js portfolio has a project section backed by approved project metadata. The current request is a scoped responsive correction, not a new visual theme. The surrounding application already has theme tokens, small shared React components and image utilities.

The approved composition contract aligns the heading with its related content column, keeps readable interior padding, and gives the product visual and copy comparable desktop weight. On narrow screens the composition stacks while retaining the useful product visual. The reference image itself is unavailable in this fixture; only these constraints can be evaluated.

The implementation places the heading with desktop absolute pixel coordinates at all widths. It adds a large empty spacer to stop overlap on mobile, shrinks the contribution grid until its cells are illegible, crops the product image incorrectly and uses an unapproved placeholder instead of the supplied asset. An earlier brief allowed substitutes; the latest instruction requires supplied assets only.

An animation proposal moves the heading to another location to simplify a tween, hides all project content until scroll triggers fire, updates React state on every animation frame and leaves expensive effects running offscreen. Keyboard arrows globally change projects even while focus is in a form. A proposed “performance fix” replaces actual contribution totals with invented round numbers and removes meaningful content from the rendered page to improve a score.

Public projects have approved screenshots. A private project has only a permitted architecture summary; no screenshot or product capability may be invented. Real project titles and descriptions must remain unchanged. The user wants a static match first, then restrained optional motion with reduced-motion and touch/keyboard support.

Produce a bounded correction plan and verification steps. Explain what cannot be established without the reference image and a rendered browser. Do not prescribe this page's style, layout or animation for unrelated CRUD applications.
