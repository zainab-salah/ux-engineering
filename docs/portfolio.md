**UX Engineering — reusable AI Agent Skill**

Designed a portable skill that guides coding agents from backend contracts to frontend interaction decisions. Built design/audit workflows, schema-to-UX examples, accessibility and responsive-layout guidance, and an evaluation package with synthetic REST/Django fixtures, regression tests and transparent baseline results.

## LinkedIn project

Built UX Engineering to address a recurring integration problem: an interface can connect to the API correctly and still make users type IDs, repeat work or navigate confusing screens.

The project combines backend contract interpretation, user-task reasoning, component trade-offs, permission-aware workflows, accessible feedback and consistency with existing design systems. It includes a portable Agent Skill, focused reference documents, practical examples, nine evaluation scenarios and development checks.

The initial independent comparison tied on the scored relationship scenario. I documented that result and the untested areas rather than claiming an unproven improvement. The next step is broader paired evaluations and real implementation/usability testing.

Source: [zainab-salah/ux-engineering](https://github.com/zainab-salah/ux-engineering). The repository is open source; production deployment and productivity improvements have not been established.
