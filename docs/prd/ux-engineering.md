# UX Engineering — product brief

## Problem and users

AI-assisted frontend integrations can satisfy API requirements while asking users to recall IDs, repeating controls, omitting workflow steps or wasting screen space. Developers using coding agents for CRM, admin and REST-backed products need better interaction decisions before code and useful audits afterward.

## Solution and scope

A portable Agent Skill with design and audit modes, supported by focused references and realistic evaluation scenarios. It translates contract evidence into interactions; preserves backend behavior; covers workflows, relationships, feedback, accessibility, responsive density and existing design systems. It includes React/Django examples without requiring those frameworks.

Not a visual theme generator, automatic form generator, schema parser, new frontend library, runtime accessibility certifier or replacement for product research. It does not modify the source work projects or publish their private data.

## Success criteria

Installable self-contained package; clear decisions and trade-offs; traceable history and external sources; reproducible package/harness checks; paired agent outputs where feasible; honest separation of automated, judged and untested behavior. No efficacy target is claimed before measurement.

## Epic and user stories

- As an integrating developer, derive a field/workflow decision from an actual contract, with accepted values and permission semantics preserved.
- As a maintainer, audit an existing CRUD interface for evidence-backed usability issues ranked by task impact.
- As an agent user, retain the product's inner-page layout and theme while reducing duplicated headings/actions and unnecessary scrolling.
- As a contributor, reproduce fixtures, inspect output evidence and evaluate a change without accepting invented benchmark claims.

Acceptance: each story is represented in the instructions, examples and validation methodology. Risks include ambiguous backend semantics, contextual component choices, baseline contamination, small samples, subjective judging and missing historical data. Mitigate with explicit uncertainty and recorded limitations.
